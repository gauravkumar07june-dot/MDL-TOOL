Download updated workbook

Writes matched dates, statuses and new rows into the MDL sheet and shifts affected formula ranges on other sheets to match. This runs entirely in your browser via a free open-source Excel engine — values, dates and formulas come out correct, but some visual styling (cell colors, borders, column widths) may not carry over exactly as in the original file. Summary-sheet bucket counts you had set manually are left untouched; use the numbers on this dashboard as the current snapshot instead.

Matching logic: exact EIDA submittal-number lookup, then title-similarity fallback for blanks and possible supersessions, with workflow-stage → status classification (Closed/VOID excluded, Closed→Approved, Initiator status starting "Approved"→Approved else Resubmission Required, "Design Consultant and Client Team"→Jacobs review, stage starting "GC"→L&T review, stage starting "Client"→TSMPL review). Runs fully client-side — no file leaves your browser.
